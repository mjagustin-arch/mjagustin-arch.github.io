Project Overview

This webpage presents an interactive mathematical animation built with the p5.js JavaScript library. Using angles, sine waves, and unit circle trigonometry, a geometric triangle continuously pulses and rotates smoothly across the canvas.

Interactive Controls

  • P Pause or resume the animation
  • W Increase rotation speed
  • S Decrease rotation speed

Mathematical Concepts

The triangle's pulsing size uses a sine wave (radius = 120 + 30 * sin(angle * 2)), while its three vertices are positioned 120° (TWO_PI / 3) apart using cos() and sin() as the angle updates every frame.
